About AgriBot

RAG-powered agriculture knowledge assistant

Project Overview

AgriBot is an AI-powered agriculture assistant designed to help beginners understand fundamental concepts in agriculture.

Instead of relying only on predefined chatbot responses, AgriBot uses Retrieval-Augmented Generation (RAG). The system retrieves relevant information from an agricultural reference document and provides that information to a Large Language Model (LLM), which generates the final response.

Why RAG?

Large Language Models can generate useful answers, but they may also produce information that is inaccurate or unrelated to a specific knowledge source.

RAG addresses this by retrieving relevant information before generating an answer.
