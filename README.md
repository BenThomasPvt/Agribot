# 🌾 AgriBot – Your Smart Agriculture Assistant 🤖

AgriBot is an intelligent web application designed to assist farmers and agricultural researchers. It combines natural language processing (NLP), machine learning, and image analysis to provide:

- 💬 Chatbot support for crop & disease queries  
- 🌿 Plant disease detection (coming soon)  
- 🎙 Voice-based chatbot interaction (coming soon)

---

## 🚀 Features

### ✅ Text-based Chatbot (LIVE)
- Built with Django + TF-IDF + cosine similarity
- Answers user queries about crops and diseases
- Trained on custom `intents.json` from real agricultural data
- Responsive chat UI with confidence-based fallback

### 🌿 Plant Disease Detection (Coming Soon)
- Upload plant leaf images
- Deep learning model (CNN) to identify diseases
- Suggests remedies and care tips

### 🎙 Voice-based Chat (Coming Soon)
- Record your voice and convert it to text
- Get spoken replies from the chatbot
- Useful for farmers with limited typing access

---

## 🧠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Django (Python)
- **ML/NLP**: scikit-learn, TF-IDF, cosine similarity
- **Image Detection (Planned)**: TensorFlow/Keras (CNN)
- **Voice Input (Planned)**: `speech_recognition`, `ffmpeg`
